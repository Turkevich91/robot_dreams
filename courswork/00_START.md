# 🎯 Lane Detection & Steering Control - Главная точка входа

## ⚡ Быстрый старт

### 🎬 Запустить в режиме ОТЛАДКИ (рекомендуется первый запуск)

```bash
python debug_integrated.py
```

**Что это даёт:**
- 🎥 Просмотр видео покадрово
- 🎨 3 фильтра: ORIGINAL / GRAY / CANNY
- 🎛️ 6 оверлеев: ROI, Hough, классификация, полиномы, руль, текст
- ⌨️ Навигация по кадрам и секундам
- 📸 Сохранение скриншотов

**Клавиши:**
```
[/]      - Один кадр ±
;/'      - Одна секунда ±
,/.      - 10 секунд ±
0        - Начало видео
SPACE    - Пауза/Воспроизведение
1/2/3    - Выбор фильтра
r/h/c/p  - Оверлеи (ROI/Hough/класс/полиномы)
w/t      - Руль / Текст
s        - Скриншот
ESC      - Выход
```

---

### 🚀 Запустить основной режим (обработка видео)

```bash
python main.py
```

**Что это делает:**
- ➡️ Обрабатывает видео frame-by-frame
- 🎨 Отображает результаты обработки
- 📊 Выводит информацию о детекции

**Клавиши:**
```
ESC      - Выход
```

---

### 🎥 Ресайзировать видео под стандартный размер

```bash
python resize_video.py --input VIDEO/input.mp4 --output VIDEO/output.mp4 --size 1280 720
```

## 🔍 Если что-то не работает

1. Проверьте, что видео находится в папке `VIDEO/`
2. Убедитесь, что путь к видео правильный в коде
3. Запустите в debug режиме: `python debug_integrated.py`
4. Смотрите скриншоты в `debug_output/` для диагностики
