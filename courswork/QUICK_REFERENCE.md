# Quick Reference Card

## 🎯 Шпаргалка для быстрого старта

### ⚡ За 5 минут

1. **Запуск основного режима:**
```bash
python main.py
```
Нажимайте `ESC` для выхода.

2. **Запуск отладки:**
```bash
python debug_integrated.py
```
Клавиши: `[`/`]` (кадры), `;`/`'` (сек), `,`/`.` (10сек), `0` (начало)

---

### 🎛️ Самые важные параметры

| Проблема | Решение |
|----------|---------|
| **Медленно** | Уменьшить `TARGET_SIZE = (960, 540)` |
| **Прыгает руль** | Уменьшить `EMA_STEER = 0.02` |
| **Теряет полосы** | Увеличить `HOUGH_MAXGAP = 80` |
| **Шумит** | Увеличить `CANNY_HIGH = 220` |
