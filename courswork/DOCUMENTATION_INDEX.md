## 🎯 Где начать?

### 👤 Новичок в проекте?
1. Прочитайте: **QUICK_REFERENCE.md** (5 мин)
2. Затем: **README.MD** → "🚀 Быстрый старт" (10 мин)
3. Запустите: `python main.py` (наблюдайте)
4. Изучите: **README.MD** → "🏗️ Архитектура" (20 мин)

### 👨‍💻 Опытный разработчик?
1. Быстро: **QUICK_REFERENCE.md** (3 мин)
2. Глубоко: **README.MD** → "🛡️ Исправления уязвимостей" (15 мин)
3. Код: docstring'и в `main.py` для интересующих функций
4. Тюнинг: **CONFIG_REFERENCE.md** → "📊 Рекомендуемые комбинации"

### 🔧 Оптимизирую параметры?
1. **CONFIG_REFERENCE.md** → "📊 Рекомендуемые комбинации"
2. **CONFIG_REFERENCE.md** → "🎯 Быстрая оптимизация"
3. Экспериментируйте с `TARGET_SIZE` и `EMA_STEER`
4. Используйте `python debug_integrated.py` для визуализации

### 🐛 Отлаживаю ошибку?
1. Запустите: `python debug_integrated.py`
2. Используйте фильтры: `1`=оригинал, `2`=gray, `3`=canny
3. Оверлеи: `r`=ROI, `h`=Hough, `c`=класс, `p`=полиномы
4. Навигация: `[`/`]` по кадрам
