# Lane Detection & Steering Control System

Автоматическое определение полос дороги и управление рулевым управлением в реальном времени с использованием компьютерного зрения.

## 🎯 Возможности

### Основная функциональность
- ✅ **Адаптивное определение ROI** — автоматическое определение области дороги с использованием vanishing point (RANSAC)
- ✅ **Детекция полос разметки** — обнаружение сплошных и штрих-пунктирных линий
- ✅ **Полиномиальная аппроксимация** — подгонка полиномов 2-го порядка к обнаруженным линиям
- ✅ **Рулевое управление** — расчет угла поворота руля на основе положения полос
- ✅ **Визуализация в реальном времени** — отрисовка ROI, линий, рулевого колеса и статуса

### Продвинутые возможности
- 🎯 **RANSAC для vanishing point** — устойчивое определение горизонта дороги на развязках и бордюрах
- 🎯 **Механизм памяти линий** — сохранение линий при кратковременных сбоях детекции (деградация 0.98)
- 🎯 **Адаптивная ширина полос** — запоминание ширины дороги из предыдущих кадров
- 🎯 **Стабильность при потере одной полосы** — доверие к видимой линии при потере второй
- 🎯 **EMA сглаживание** — плавные переходы полиномов и углов поворота
- 🎯 **Анизотропная морфология** — оптимизированная обработка для полос на скоростной трассе

## 📊 Конфигурация

### Основные параметры (`main.py`, строки 16-43)

```python
# Размер кадра
TARGET_SIZE = (1280, 720)   # (W, H)
RESIZE_MODE = "fit"         # "fit" (letterbox) или "stretch"

# Canny Edge Detection
CANNY_LOW, CANNY_HIGH = 60, 180

# Hough Line Detection
HOUGH_THRESH = 30           # порог детекции линии
HOUGH_MINLEN = 40           # минимальная длина линии (px)
HOUGH_MAXGAP = 50           # максимальный разрыв между точками (px)

# Сглаживание линий
EMA_POLY = 0.30             # коэффициент EMA для полиномов (0.30 = 30% новое, 70% старое)
EMA_STEER = 0.05            # коэффициент EMA для угла поворота (очень плавно)
RATE_LIMIT = 1.5            # макс изменение угла за фрейм (град)
STEER_MAX = 25.0            # максимальный угол руля (град)

# Память линий
LANE_MEMORY_FRAMES = 20     # макс фреймов с "памятью" линии
LANE_POLY_DECAY = 0.98      # деградация полинома без детекции (-2% в фрейм)

# ROI определение
SKY_CROP = 0.35             # исключить верх кадра (небо, 35%)
HOOD_CROP = 0.315           # исключить низ кадра (капот, 31.5%)
ROI_TOP_HALF_WIDTH_RATIO = 0.30  # ширина верхней части ROI
```

## 🏗️ Архитектура

### Основные компоненты

#### 1. **Обработка изображения** (`compute_edges()`)
- Конвертация в оттенки серого
- Gaussian blur (5×5)
- Canny edge detection (единственный вызов в фрейм!)

#### 2. **Определение ROI** (`detect_road_roi()`)
- Использует готовые edges
- Находит горизонтальные линии через Hough
- **RANSAC** для поиска vanishing point (устойчив к шуму)
- Автоматическое определение горизонта капота
- Строит трапецию ROI с EMA сглаживанием

#### 3. **Детекция линий** (`detect_lines()`)
- Исключает 2-3px рамку letterbox (от артефактов)
- **Анизотропная морфология** (15×3 прямоугольник вместо эллипса)
- Применяет ROI маску + Y-маску (границы)
- HoughLinesP в ограниченной области

#### 4. **Подгонка полиномов** (`fit_lane()`)
- Фильтрация по углу наклона (|k| ∈ [0.5, 3.0])
- Удаление выбросов (2.5σ outlier detection)
- Валидация коллинеарности
- Защита от RankWarning (np.errstate)

#### 5. **Отслеживание линий** (`LaneTracker`)
- Сохранение ширины полосы из истории
- Деградация полинома (×0.98) при отсутствии детекции
- Память до 20 фреймов (затем забывает)

#### 6. **Рулевое управление** (`steering_from_lanes()`)
- **Адаптивная ширина полосы** из памяти (не константа!)
- При одной видимой линии: смещение на пол-ширины
- При обеих линиях: центр полосы + сохранение ширины
- Расчет: ошибка позиции + угол наклона

#### 7. **Визуализация**
- Отрисовка ROI (жёлтый контур)
- Зелёная линия (левая) — яркая при детекции, тусклая из памяти
- Красная линия (правая) — яркая при детекции, тусклая из памяти
- Рулевое колесо (RGBA, premultiplied alpha compositing)
- Статус (STRAIGHT/LEFT/RIGHT + угол)

## 🎓 Ключевые алгоритмы

### RANSAC для Vanishing Point
```
1. Случайно выбрать точку пересечения как гипотезу VP
2. Считать "inliers" — точки в пределах threshold (30px)
3. Если больше inliers чем раньше → сохранить гипотезу
4. Уточнить VP как взвешенное среднее inliers
5. Повторить 100 раз, выбрать лучшую гипотезу
```

### EMA сглаживание
```
poly_new = alpha * poly_detected + (1 - alpha) * poly_previous
Где:
  alpha = 0.30 для полиномов (30% новое, 70% старое)
  alpha = 0.05 для угла рулевого (5% новое, 95% старое)
```

### Деградация памяти линии
```
if no_detection:
    frames_missing += 1
    if frames_missing <= LANE_MEMORY_FRAMES:
        poly *= LANE_POLY_DECAY  # умножить на 0.98 (-2% в фрейм)
    else:
        poly = None  # забыть линию
```

## 🐛 Известные ограничения

- ⚠️ Не работает на очень крутых поворотах (>60°)
- ⚠️ Требует хорошего освещения
- ⚠️ Чувствителен к погодным условиям (дождь, снег)
- ⚠️ Полосы дороги должны быть достаточно контрастны
- ⚠️ Не обрабатывает перестроение между полосами
